# v0.1.40

第一个对外发布的版本。连接、浏览、同步到相册、两处删除、后台传图都能用，在小米 15 和一加 9RT 上测过。

## 下载

- `z-sync-0.1.40-40.apk`（41 MB，Android 12 以上）
- SHA-256：`5d5fb5368c561d590a4d52535c5def249daf5290ccca6bcca553c73b539ee1ea`

```bash
shasum -a 256 z-sync-0.1.40-40.apk
```

## 装完先做一件事

**小米 / 红米（HyperOS、MIUI）：设置 → 应用设置 → 应用管理 → Z-Sync**

1. **省电策略** → **无限制**（关键项，不设就会切后台断连）
2. **通知管理** → 允许通知，里面那条「**相机连接**」也要允许

改完验证：连上相机开始传图，切到别的应用待一两分钟再回来，连接应该还在。

一加 / OPPO / realme（ColorOS）：菜单叫「耗电管理」，设成「允许完全后台行为」。但这套系统实测连这个也不认，切走后几秒还是会断，那台机器上只能在前台传完。

## 这个版本能做什么

**连接**

- 在应用里加入相机热点，密码只输一次，之后自动重连上次那台
- 热点没开就一直等扫描；已连上又断了自动重试最多三次
- 一分钟连不上进「找不到相机」页，给分步排查
- 连不上和密码错分开提示；只有当前热点自己报认证失败才清密码

**浏览**

- 按相机拍摄日分组，没有日期的归到「日期未记录」
- 最早 / 最新切换顺序，大图 / 列表切换版式，一屏 4 / 6 / 9 张
- 格式筛选：全部、JPEG、RAW / NEF、MOV、MP4
- 缩略图分页加载，每页 10 张

**同步到相册**

- 原文件名、原 EXIF 原样写进 `Pictures/Z-Sync`，不改内容也不改拍摄时间
- 相册里已有同一张就跳过
- 1 MiB 分块流式下载，中断后从已写入位置继续
- 进度卡显示 `1/4`、已保存几张、还剩几张

**下载历史**

- 照片页右上角「下载」看这次存了哪些
- 点开看大图；**只存了 RAW 也能看**，应用会从 NEF 里抽出内嵌的 JPEG 预览
- 从这里删除只删手机相册，不动相机

**从相机删除**

- 同一次快门的 JPEG 和 NEF 一起删，相机里标了保护的留下
- 删除请求攒到空闲心跳时一次提交，避免每删一张机身就切一次回放页

**后台与日志**

- 连接期间常驻通知，传图时显示「正在保存 1/3 张照片」
- 连接页底部「导出日志」可以把日志分享出来，超过 6 小时自动清理

## 已知限制

- ColorOS 上后台传图做不到（系统冻结应用并销毁 socket，应用层无解）
- 相机热点关了要手动重开（Z30 没有「保持热点常开」的选项）
- RAW 显示的是 NEF 内嵌的 JPEG 预览，不是 RAW 解码
- 一次读完整个目录，照片特别多时首次加载慢（默认只加载最近 100 张还没做）
- 界面只有暗色

## 安装说明

首次安装要允许「安装未知来源应用」。这个包是正式签名的 release 版本（`CN=Z-Sync`），不可调试。

如果之前装过用 debug key 签的测试包，装这个会报签名不一致，需要先卸载——**卸载会清掉已保存的相机密码，需要重新输一次**。
