# 功能

新的功能写在这里，一条一个勾。勾上表示这一条已经写进某个版本。版本号写在勾的后面。装到手机上之前，测试看该版本的测试对照。不要写进缺陷那一份。

每编译或发布一个版本，另写一份该版本的测试对照，列出这一版里有哪些缺陷和功能、各自怎么验。

## 下载进度

界面稿在 [本次下载](../design/pages/07-download-progress.html)。做法在 [下载进度](download-progress.md)。底部那条「本次 0 张」试过，后来改掉了，不放在屏幕最底下。

- [x] 0.1.16。只留正在下载的那一条进度条。
- [x] 0.1.16。张数用斜杠，写成 `1/4`、`4/4`，不用短横线。
- [x] 0.1.16。同时显示已保存几张、还剩几张。跳过的不算进已保存。
- [x] 0.1.16。「下载」在照片页右上角，不在底部。还没有这次下载时只写「下载」；有了之后写成「下载 · 本次 N 张」。
- [x] 0.1.16。点「下载」进入本次下载页。每一行是缩略图加文件名。
- [x] 0.1.16。点某一行打开大图。已经存进相册的是完整颜色。还没下完的变淡，并写「还没下完」。
- [x] 0.1.16。大图上有返回，回到本次下载。
- [x] 0.1.16。大图上有「从相册删除」。先问「从相册删除这张照片？」。确认后从这次的下载记录里去掉，并从相册删掉这一张。
- [x] 0.1.16。「同步到相册」只在点了「选择」、并且至少勾了一张之后才出现。

## 后台保活与通知

0.1.29 起有前台服务，0.1.33 起通知文案定稿，0.1.34 起保存过程报进度。方案和实测结论在 [后台断流方案](../solution/coloros-background-drop.md)。

- [x] 0.1.29。连接期间挂前台服务，通知常驻，防止切后台被系统回收。
- [x] 0.1.33。通知文案从「正在连接相机」改成「正在运行」，不再和应用名重复。
- [x] 0.1.34。保存时通知显示「正在保存 1/3 张照片」，逐张推进；开始时先写「正在保存 3 张照片」。
- [x] 0.1.36。照片页顶部提示去系统设置放开后台限制，按钮直接打开应用设置页。
- [ ] 小米 / HyperOS：省电策略设「无限制」+ 允许通知，实测切后台十几分钟不断。这条要求写进 [上手说明](../guides/setup.md)。
- [ ] 一加 / ColorOS：系统会冻结后台应用并销毁 socket，前台服务、Doze 白名单、厂商「完全允许后台行为」都挡不住。不再处理。

## 应用内日志

以前只能靠 adb 抓 logcat，测试的人手上只有手机，等于拿不到日志。

- [x] 0.1.36。日志同时写进 `Android/data/app.zsync/files/logs/`，连接页底部「导出日志」走系统分享。
- [x] 0.1.37。超过 6 小时的日志文件自动删掉；另外单个文件 2 MB、最多留 5 个。

## 已经落地的其余功能

这些是 0.1.21 到 0.1.38 之间做完并验过的，详细验收在 [任务清单](../backlog/task-tracker.md) 各节里。

- [x] 0.1.21。连接状态机统一：搜索、加入 Wi-Fi、打开 PTP、加载照片、传输文件是不同状态，界面和日志不把它们都写成「连接中」。
- [x] 0.1.21。持有相机网络租约，只有在系统明确 `onLost`、人确认取消或应用结束会话时才释放。
- [x] 0.1.21。PTP 失败先重试操作，再在同一个 `Network` 上重建会话；不主动释放租约。
- [x] 0.1.21。相机本地日期分组，日期标题左对齐，没有日期的归到「日期未记录」。
- [x] 0.1.21。格式筛选 `全部 / JPEG / RAW / NEF / MOV / MP4`，只排除 NDF。
- [x] 0.1.21。视频与照片一样可列出、选择、传输原文件、存进 `MediaStore.Video`、删除；能内嵌播放就内嵌，否则回退系统播放器。
- [x] 0.1.21。传输队列 + `.part` 断点续传，部分文件不进系统相册。
- [x] 0.1.24 ～ 0.1.28。一批删除、去重、缩略图加载、连接文案的修复，见 [缺陷](../bugs/bugs.md)。

## 分批加载

还没写进应用。相机照片很多（例如几千到一万张）时，不要一次把全部预览都加载出来。默认只加载最近 100 张，再给一个按张数或按时间选范围的入口。方案在 [加载进度](../solution/loading-progress.md)，两条一起做，因为拆枚举那一步是共同前置。

- [ ] 默认只加载最近 100 张，不再一次读完整张卡。
- [ ] 提供加载范围选项：按张数（最近 100 / 500）或按时间（最近一周、最近半年、全部）。
- [ ] 列表顶部说明当前范围，并给「加载更早」的入口。
- [ ] 范围切换后，顺序和分组仍按相机本地拍摄日排列。
- [ ] 加载过程显示 `已加载 231 / 1000`，进度条按比例走（见下面的「加载进度」）。
