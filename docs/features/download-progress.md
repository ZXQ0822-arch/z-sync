# 下载进度

**已经落地**，0.1.16 起就在应用里。这一份留的是页面结构和取舍记录，不是待办。

现在选中多张再同步时，每张照片各有一条进度条，叠在一起，一张接一张往前走。要改成下面三件事。状态都是未完成。

## QL-24 只显示正在下载的那一条

**状态：** 未完成

**说明**

同步到相册时，屏幕上只留当前这一张的进度条，不要把每一张的进度条叠出来。条旁边写当前是第几张、一共几张，用短横线连起来。第一张是 `1-10`，第二张是 `2-10`。这一张下完再换成下一张的条。

**验收**

- [ ] 一次选多张时，照片页上同时只有一条进度条。
- [ ] 条上或条旁边能看到 `1-10` 这种「当前-总数」。
- [ ] 数字随当前这一张增加，总数不变。
- [ ] 没有在下载时，不摆一排空的进度条。

**在一加 9RT 上怎么验**

1. 连上相机，选 10 张，点「同步到相册」。
2. 照片页应只有一条进度条，先显示 `1-10`。
3. 第一张结束后，条换成下一张，文字变成 `2-10`，不应同时出现 10 条。

## QL-25 已保存几张、还剩几张

**状态：** 未完成

**说明**

同一条进度旁边写两句数：这次已经存进相册的张数，以及还没存完的张数。跳过的已在相册的照片不要算进「已保存」。还剩的张数随着当前这张结束往下减。

**验收**

- [ ] 下载过程中能看到已保存的张数。
- [ ] 下载过程中能看到还剩的张数。
- [ ] 已保存加上还剩，等于这次要处理的张数；跳过的单独说明，不混进已保存。
- [ ] 全部结束后，还剩是 0。

**在一加 9RT 上怎么验**

1. 选 10 张，其中 2 张相册里已经有。点「同步到相册」。
2. 开始时应能看到已保存 0，还剩 8（或把跳过的 2 张单独写出来）。
3. 每存完一张，已保存加 1，还剩减 1。
4. 结束后还剩为 0，已保存是新存进去的张数。

## QL-26 本次下载页

**状态：** 未完成

**说明**

照片页上有一个可以点的入口，例如「下载」。点进去是本次下载的一页，写清这一次一共存进相册多少张。页上可以列出每一张的结果，但不要再给每一张一条进度条。下载进行中点进去，也能看到当前的 `当前-总数`、已保存和还剩。

**验收**

- [ ] 照片页有「下载」或同等入口，点得开。
- [ ] 页上写着本次存进相册的总张数。
- [ ] 进行中打开这一页，能看到当前的 `当前-总数`、已保存和还剩。
- [ ] 结束后打开这一页，总张数停在这一次实际保存的数量。
- [ ] 从这一页能回到照片页。

**在一加 9RT 上怎么验**

1. 选几张，点「同步到相册」。下载过程中点「下载」。
2. 应看到当前是第几张、一共几张，以及已保存和还剩。
3. 等这次结束，再点进「下载」。总张数应等于这次新存进相册的张数。
4. 返回后仍是照片页。
