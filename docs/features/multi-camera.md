# 多相机连接

**状态：** 延期参考，不在当前路线

当前范围只保存上一台成功连接相机的完整 SSID、密码和现有 GUID，并提供重连上一台。新相机成功连接后覆盖上一份资料，不维护多台凭据列表或完整历史。QL-06 与 QL-07 只有在真实需要第二台相机时才重新评估。

当前 Nikon Z30 热点识别规则仍集中定义，但不扩展成用户可配置的多品牌前缀。下面保留原来的设计、验收和真机步骤作为延期参考，不表示正在排期。

下面是早期拟定的独立版本方案。若将来重启，仍应单独实施，不与传输或连接可靠性混在一次改动里。

## 为什么要做

现在只记住一台相机的名称和密码。两台 Z30 都开着 Wi-Fi 时，没有选择这一步，第二台永远连不上。

连接页现在会停在「点允许」三个大字上。这一版拿掉这个提示，改成一份像任务切换器那样的相机列表，人选哪一台再连。

## 要记住什么

每次连接成功，把这台相机的完整热点名称和密码存下来。例如 `NIKON_Z_30_12345`。不是只留最近一台，也不是只留「尼康 Z30」这种简称。

已经存过的同一名称，用这次的密码覆盖。密码只存长度以外的内容，日志里仍然只写密码长度，不写密码本身。

## 连接页上的列表

打开连接页就看到这份列表，不再出现「点允许」。

列表像切换最近用过的应用：每一台相机一行，点一行就是选它。上面三块都要有：

1. **上次连接。** 置顶一行，写完整热点名，例如 `NIKON_Z_30_12345`，并标明这是上次连上的那一台。还没成功连过任何相机时，不编造这一行。
2. **当前扫到的相机。** 名称以前缀匹配上的热点各占一行，都可以点。默认前缀是 `NIKON`。家里其它 Wi-Fi 不进这份列表。
3. **连上一次。** 列表上有一个快捷操作，一点就用已存密码去连上次那一台。上次那一台不在时，这个操作不可用，不拿别的热点顶上。

上次那一台如果也在本次扫描里，仍然只占一行，同时标成上次连接。「连上一次」指向这一行。

## 扫到几台时怎么走

先扫描。只把名称以前缀匹配上的热点当作相机。

- 扫到正好一台：用已经存过的密码自动连接。这台还没有存过密码时，停在密码框，名称已经填好。列表里仍能看见这一台。
- 扫到两台或更多：停下来，等人在列表里点一台。选中的那台有密码就直接连，没有就再要密码。不要自己挑信号最强的那台。
- 一台都没扫到：不显示空的相机行，改为密码框，让人手工输入一台还没见过的相机。已经存过的「上次连接」和「连上一次」仍然在。

人选好、或者正好一台而自动连接时，系统若再弹出自己的网络允许框，那是系统界面。应用自己的连接页上不再做「点允许」。

## 前缀

匹配按前缀，不是写死整段 `NIKON_Z_30`。

现在的默认前缀是 `NIKON`。`NIKON_Z_30_12345` 能匹配上。前缀放在一处列表里，以后要加别的牌子，只往列表里加一项，不改扫描和选择的流程。

## 验收

- [ ] 连接页没有「点允许」三个大字，打开就是相机列表。
- [ ] 上次连上的相机在列表顶部，名称是完整热点名，例如 `NIKON_Z_30_12345`。
- [ ] 当前扫到的、前缀匹配的热点各有一行，可以点。
- [ ] 有「连上一次」，且只连上次那一台。
- [ ] 每台成功连接过的相机都留下完整热点名和密码。
- [ ] 扫到正好一台、且已有密码时，自动连接。
- [ ] 扫到多台时停住，等人点列表里的一台，不自己挑一台连上。
- [ ] 一台都没扫到时出现密码框。
- [ ] 日志里不出现密码本身，只出现密码长度。

## 在一加 9RT 上怎么验

1. 只开一台 Z30 热点，打开 Z-Sync。连接页应是相机列表，没有「点允许」。应自动连上，列表里能看到完整热点名。
2. 连上一次后断开。列表顶部应是「上次连接：NIKON_Z_30_12345」这种完整名称，点「连上一次」应再连这一台。
3. 两台都开热点。应出现两个完整名称，停住不自动连。点第二台才连第二台。
4. 两台都关掉。不应出现「点允许」。应出现密码框，「上次连接」和「连上一次」还在。
5. 家里其它 Wi-Fi 开着时，不应被列成相机。

## 真实需要第二台时再做

只有出现真实第二台相机需求时，才单独开一版重新验证下面的方案。不要和下载进度、热点重连混在同一次改动里。

现在密码存在一个加密文件里，只留最近一台的名称和密码。认相机是看名称里有没有 `z30`，或者是不是这台已存的名称。连接页还不是相机列表。

这一版按下面的顺序做：

1. 把「一台名称加密码」改成一份相机列表。同一名称再次连上，用新密码覆盖旧的。日志仍然只写密码长度。
2. 若届时仍需要多品牌前缀，再把规则收到一处列表，默认是 `NIKON`。扫描和选择都问这一处，不再各自写死 `z30`。这与延期的 QL-07 一起重新评估。
3. 连接页改成这份说明里的列表：上次连接、当前扫到的相机、连上一次。拿掉应用自己的「点允许」。系统若再弹出网络允许，那仍是系统界面。
4. 先扫描再决定：正好一台且已有密码就自动连；两台或更多就停住等人点，不挑信号最强的；一台都没有就显示密码框，已保存的上次连接还在。

验收和手机上的步骤仍是上面那两节，不因为换了存放位置而减少。

## 这一版不做

- 不装到手机上，除非另说。
- 不改 0.1.9 里已经装上的「找不到相机」文案，也不改 0.1.10 里的预览旋转、长按信息和同步到相册。
- 不在这份任务里做原片同步、删除或边框。
