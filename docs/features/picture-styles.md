# 拍照风格

**状态：** 未完成。应用里还没有这一页。数字先记在这里。可点的页面在 [风格](../design/pages/08-style.html)。

这些是写进 Z30 的优化校准、白平衡和动态 D-Lighting，不是传到手机后再加的滤镜。只影响之后拍的 JPEG。NEF 仍是原始数据。

名字用配方自己的名字，不写成富士原厂模拟。这里面没有 Classic Chrome。作者写过，最接近正片感觉的是 Fujichrome，不是 Velvia。

## 先用哪三套

| 想拍什么 | 点这个 | 为什么 |
| --- | --- | --- |
| 白天拍人 | Fujichrome | 清晰度和对比往低，肤色柔，颜色仍亮。白平衡是直射阳光。 |
| 白天拍景 | Silver Slide | 饱和高，清晰度略加，适合白天的风景和城市。 |
| 电影感，要质感 | Cinema Color | 漂白，清晰度往低，直射阳光再往琥珀偏。 |

拨盘放在 P 或 U1，不要放 AUTO。ISO 建议不超过 3200，只作提示，不改相机的 ISO。

机身上分三处设：拍摄菜单的「设定优化校准」选创意项再进细项；白平衡和偏移单独设；动态 D-Lighting、高感光度降噪也在拍摄菜单里。关机后还要保留，就在相机菜单里把当前设置存进 U1。应用不替人注册 U 档。U 档记不住「管理优化校准」里的 C-1 到 C-9，所以这一版不依赖那些槽位。

## 出处

第一批 11 套来自 Ritchie Roesch 在 Fuji X Weekly 发布的文章，2022-07-03：[11 Nikon Z Film Simulation Recipes](https://fujixweekly.com/2022/07/03/11-nikon-z-film-simulation-recipes/)。作者写明适用于 Z30、Z50、Zfc，当时在 Zfc 上做的。全画幅 Z 可能略有差别，这份只对 Z30 用。

下面的数字按原文填写。中文是机身菜单里的叫法，方便在国行界面里找到那一项。

GitHub 上的 `.NP3` 集合（例如 shouryan01/Nikon-Recipes）要较新的机身和 Nikon Imaging Cloud，Z30 装不了。不放进第一批。

页面上的分类是按用途归的，不是作者原文的标题。Tungsten Dawn 是暖光和混合光，不放进白天那两类，只在「全部」里。

## 页面怎么走

应用里还没有。暗房稿按这个走，用来在不连相机时看这一页。

1. 照片页上有「风格」。点开后盖在照片上，不离开照片。
2. 上面是分类：白天拍人、白天拍景、电影感、全部。名单只写名字和一句话。使用中的那一套才标「使用中」。
3. 点一条进入参数页，能看完上面表里的每一项，以及出处。点返回回到名单。只是点开看，不会把上一套从「使用中」拿掉。
4. 参数页上点「用这个拍」。稿里有一个拨盘，可以在 P 和 AUTO 之间拨。停在 AUTO 时不标成使用中，只提示拨到 P 或 U1。停在 P 时标成使用中，照片页按钮写成「风格 · 名字」。
5. 标成使用中之后仍要写明：这一版还不能写进 Z30，按数字在机身菜单里设一次。写入要等需求里的 S0.5 读到 `0x90CC`、写进 `0x90CD`。写不进去就不做下发按钮，也不假装已经成功。
