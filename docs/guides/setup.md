# Z-Sync 使用手册（纯文本摘要）

**完整手册是 [setup.html](setup.html)，带侧边目录，用浏览器打开。这一份只是要点摘录，以 HTML 为准。**

把尼康相机里的照片和视频存进手机相册。

## 前置条件

- 手机：**安卓 12 或更高**。
- 实测机型：小米 15（HyperOS / 安卓 16）、一加 9RT（ColorOS / 安卓 14）。
- 相机：尼康 Z30。其它尼康 Wi-Fi 相机理论上一样，但我只验证过 Z30。
- 装好 Z-Sync，相机开着，知道相机屏幕上的密码。

## 第一次连接

**只有第一次要输密码。**密码在相机屏幕上，输一次应用会记住。

1. 相机：按 `MENU` → 设定菜单（图标像扳手）→ 连接至智能设备（像手机）→ Wi-Fi 连接（Wi-Fi 弧线）→ 建立 Wi-Fi 连接（像两个扣在一起的环），停在这一页。
2. 手机：打开 Z-Sync，权限全给（附近的设备、通知、位置），填相机屏幕上的密码，点「连接相机」。
3. 系统弹窗里选中 `NIKON` 开头的网络，点「允许」或「连接」。**别按返回**，按返回等于取消。
4. 等一两秒自动进照片页。

不要把相机连家里路由器，也不要去系统「设置 → WLAN」手动连。用之前把 SnapBridge 退干净。

## 看照片、存到手机

- 照片按拍摄日期分组；右上角切「最新 / 最早」，中间切「大图 / 列表」和一屏 4 / 6 / 9 张；可按 JPEG / RAW / MOV / MP4 筛。
- 存到相册：点「选择」→ 勾照片 →「同步到相册」→ 等进度走完。
- 照片进 `Pictures/Z-Sync`，视频进 `Movies/Z-Sync`，相册里是两个文件夹。
- 已经在相册里的会自动跳过。
- 「下载 · 本次 N 张」是这次的记录，点开能看大图；只存了 RAW 也能看，应用会抽 NEF 里内嵌的预览图。

## 删除：两个地方删的不是同一样东西

| 在哪里删 | 删掉的是 | 确认框 |
| --- | --- | --- |
| 照片大图里的「删除」 | 相机存储卡上的那张 | 「从相机删除这张照片？」 |
| 「下载」历史里的「从相册删除」 | 手机相册里的那张 | 「从手机相册删除这张照片？」 |

同一次快门的 JPEG 和 NEF 一起删；相机里标了保护的删不掉。

## 一次设置，长期省事

**相机**：`MENU` → 自定义设定菜单（铅笔图标）→ **c3 电源关闭延迟** → 待机定时器 → 改 **10 分钟**。再把 设定菜单 → **节能（照片模式）** → **禁用**。相机里没有「让热点常开」的选项。

**手机（关键）**：传图时切到别的应用会断，是因为系统把应用掐掉了。

- 小米 / HyperOS：**设置 → 应用设置 → 应用管理 → Z-Sync** → **省电策略** 改 **无限制**；**通知管理** 打开允许通知，里面「**相机连接**」那条也要允许。
- 一加 / OPPO / realme（ColorOS）：菜单叫「耗电管理」，但实测即使设成「允许完全后台行为」，切走后几秒还是会断。这些手机上请停在照片页传完再切走。

验证：连上相机开始传图，切到别的应用待一两分钟再回来，连接还在就对了。设对了通知栏会一直挂「Z-Sync · 正在运行」。

## 再次连接

**不用再输密码。**只有三种情况需要重输：相机密码改过、在手机上删过保存的记录、换了另一台相机。

相机重开 Wi-Fi → 打开 Z-Sync 等它自己连 → 选照片同步。停在连接页不动就点「上次连接 NIKON_Z_30_xxxxx」右边的「连接」。

## 出问题了

按屏幕上写的那句话查：

- **「找不到相机」**：相机 Wi-Fi 没开、SnapBridge 还在后台、或没给「附近的设备」权限。点「继续连接」→ 弹窗「相机Wi-Fi已开启」→「确认」。
- **「Wi-Fi 密码错误」**：看相机屏幕当前的密码，重新输，点「再次连接」。
- **「连接已断开，正在重新连接」**：应用会自己再连一次。连不上就重开相机 Wi-Fi，回应用点「继续连接」。
- **切出去回来就断**：省电策略没设成「无限制」，或通知被关掉了。
- **「相机正连着别的应用」**：退出 SnapBridge，手机「设置 → WLAN」里忘记相机网络，回来点「重试」。
- **相册里找不到**：照片在 `Pictures/Z-Sync`，视频在 `Movies/Z-Sync`，去文件夹里找。
- **连上相机上不了网**：正常的，相机 Wi-Fi 没有外网，用完断开就好。

## 怎么发日志

1. 先让问题重现一次。
2. 回到连接页（断开后会自己回去）。
3. 点页面最下面、版本号右边的「**导出日志**」。
4. 选微信或邮件把它发出来。

日志里不含照片内容；超过 6 小时自动清理，手机上最多留 5 个。出问题尽快导。

发的时候顺便说一下手机型号、系统版本、哪一步出错、屏幕上那句话、大概几点。
