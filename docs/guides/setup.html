Z-Sync 使用手册

适用于尼康 Z30。其它尼康 Wi-Fi 相机理论上兼容，当前以 Z30 验证为主。

快速上手四步曲

  1. 相机：按 MENU → 设定菜单 → 连接至智能设备 → Wi-Fi 连接 → 建立 Wi-Fi 连接，保持在此页面。
  2. 手机：打开 Z-Sync，输入相机屏幕上显示的密码，点击「连接相机」。
  3. 系统弹窗：选中 NIKON 开头 的网络，点击「允许」或「连接」。（请勿点击返回）
  4. 等待一两秒即可自动进入照片流页面。勾选需要保存的照片，点击「同步到相册」。

准备工作

项目系统与设备要求
手机系统Android 12 或更高版本
已验证手机小米 15（HyperOS / Android 16）、一加 9RT（ColorOS / Android 14）
支持相机尼康 Z30
首次连接必备安装 Z-Sync；相机处于开机状态；获取相机屏幕上显示的 Wi-Fi 密码

⚠️ 保持默认，请勿修改相机 Wi-Fi 名称

为了做到连接体验简单清晰，本应用目前仅自动识别并支持以 NIKON 开头的默认网络名称 (SSID)。请不要擅自在相机里更改 Wi-Fi 名称。后续版本可能会开放自定义名称的支持。

相机同一时间仅支持连接一台设备。使用 Z-Sync 前，请确保已彻底退出 SnapBridge（尼康官方 App）。若此前曾使用 SnapBridge 连接过该相机，请前往手机「设置 → WLAN」找到 NIKON 开头的网络，点击「忘记此网络」。

首次连接指南

首次连接需进行完整的安全验证（输入相机密码及授予系统网络权限）。此操作仅需执行一次。密码会显示在相机屏幕上，输入一次后应用将自动记忆，后续无需重复输入。

第一步：相机端开启 Wi-Fi

  1. 相机开机，按下 MENU 键。
  2. 进入「设定菜单」。（顶部菜单栏的扳手图标）
  3. 依次点击：「连接至智能设备」 → 「Wi-Fi 连接」 → 「建立 Wi-Fi 连接」。
  4. 保持当前页面常亮。屏幕将显示网络名称（SSID）和密码，请确保屏幕未熄灭。

注意：请勿将相机连接至家用路由器，也不要在手机系统的「设置 → WLAN」中手动连接。所有连接操作均需在 Z-Sync 应用内完成。

第二步：手机端建立连接

  1. 打开 Z-Sync，并授予全部必要权限：
    • 附近的设备：用于搜索并发现相机热点。
    • 通知：用于保障后台稳定传输照片。
    • 位置：Android 系统要求，仅用于获取 Wi-Fi 列表，本应用不记录任何位置信息。
  2. 输入相机屏幕上的密码，点击「连接相机」。
  3. 在系统弹窗中，选中 NIKON 开头的网络，点击「允许」或「连接」。这是系统级强制流程。
    切勿点击“取消”或按系统返回键。否则将中断连接流程，需要从头重新操作。
  4. 等待片刻。系统将自动进入照片浏览页，看到照片即代表连接成功。

保持稳定连接的最佳设置

相机端：延长屏幕常亮时间

强烈建议相机的默认休眠时间较短（约 30 秒），一旦屏幕熄灭，Wi-Fi 将同步断开。

  1. 按 MENU → 找到「自定义设定菜单」（铅笔图标）。
  2. 进入「c3 电源关闭延迟」。
  3. 选择「待机定时器」，建议修改为 10 分钟。如需长时间传图可选择「无限」。

此外，请前往 MENU → 设定菜单 → 将 节能（照片模式） 设置为 禁用，防止屏幕提前变暗。

手机端：配置后台运行权限

重要设置若未正确配置此项，传输照片期间切换至其他应用将导致连接立即中断。

以 小米 / 红米（HyperOS、MIUI）为例：请前往 设置 → 应用设置 → 应用管理 → Z-Sync，调整以下两项：

  1. 省电策略 → 修改为 无限制。这是保持后台连接的核心，若保留“智能限制”，切出应用几秒后连接便会断开。
  2. 通知管理 → 开启“允许通知”。若通知设置中包含名为 相机连接 的子选项，请一并开启（如有此项，它是保持后台连接的关键；若无该选项，保持主通知开启即可）。

设置成功后，通知栏会常驻显示「Z-Sync · 正在运行」。传图时会变更为「正在保存 X/X 张照片」。

一加 / OPPO / realme（ColorOS）用户注意：受系统限制，即便在“耗电管理”中设置为“允许完全后台行为”，切出应用仍可能断开。建议在这类手机上保持在照片页，直至传图完成。

日常再次连接

完成首次连接后，后续使用无需再输入密码。只需开启相机 Wi-Fi 并打开 Z-Sync，系统将自动建立连接。 只有在以下三种情况需重新输入：相机密码被修改、在手机上清除了保存的记录、或更换了另一台相机。

  1. 相机端开启 Wi-Fi。与首次连接相同，每次开关机后均需重新开启。
  2. 打开 Z-Sync，等待自动连接。系统弹窗通常不会再次出现。
  3. 选择照片，点击「同步到相册」。

若停留在连接页无响应，请点击「上次连接 NIKON_Z_30_xxxxx」右侧的「连接」按钮。若密码已更改，则需重新输入新密码。

照片查看与保存至相册

照片页概览

  • 照片按拍摄日期分组，同一天的照片归类在同一标题下。
  • 右上角可切换「最新 / 最早」排序，中间可切换「大图 / 列表」视图及一屏 4 / 6 / 9 张的显示密度。
  • 支持按格式筛选：全部、JPEG、RAW / NEF、MOV、MP4。
  • 点击单张照片可查看大图、旋转方向，下方显示文件名、大小、光圈及镜头信息。

保存至手机相册

  1. 点击右上角「选择」。
  2. 勾选需要保存的照片。（未勾选任何照片时，底部不会显示同步按钮）
  3. 点击「同步到相册」，等待进度条完成。进度卡片会实时显示 1/3、已保存数量及剩余数量。
  4. 打开手机相册，查找 Z-Sync 专属相册。
内容类型保存路径
照片（JPEG、NEF）Pictures/Z-Sync
视频（MOV、MP4）Movies/Z-Sync

照片与视频在手机相册中存放于两个不同的独立文件夹。相册中已存在的同名文件会自动跳过，不会产生重复。

本次传输记录

照片页右上角的「下载 · 本次 3 张」记录了本次连接成功保存的内容。点击进入后，每行显示缩略图与文件名，点击可查看大图。即使仅保存了 RAW 格式，应用也会提取 NEF 文件自带的预览图供查看。

照片删除说明

⚠️ 双端删除的区别与注意事项

操作位置删除对象确认框提示
照片大图页面的「删除」相机存储卡上的原文件「从相机删除这张照片？」
「下载」记录中的「从相册删除」手机相册中的已下载文件「从手机相册删除这张照片？」
  • 若在相机端删除：同一次快门生成的 JPEG 和 NEF 文件将被同步删除。
  • 相机中被标记为「保护」的照片无法通过应用删除。
  • 若从手机相册中删除：相机存储卡上的原文件不受任何影响。

常见故障排除

请先确认屏幕上的具体提示信息，再对照以下情况进行排查。

找不到相机

页面标题显示「找不到相机」，下方提示「连接已超时一分钟」，代表系统在一分钟内未扫描到相机热点。

  1. 确认相机 Wi-Fi 页面是否依然常亮（屏幕需显示网络名和密码）。若已熄灭，请参考「首次连接指南」重新开启。
  2. 点击「继续连接」，系统将弹出「相机 Wi-Fi 已开启」的确认框。
  3. 若相机确已开启请点击「确认」；若未开启请点击「取消」，先前往相机端操作。

若频繁超时，常见原因包括：SnapBridge 仍在后台运行占用通道，或未授予应用「附近的设备」权限。

密码错误

屏幕提示「Wi-Fi 密码错误」。

  1. 检查相机屏幕上当前显示的密码（相机重启热点后，密码可能会发生变更）。
  2. 在输入框中填入最新密码，点击「再次连接」。

连接中途断开

屏幕提示「连接已断开，正在重新连接」，应用将自动尝试重连（需等待十几秒）。

  • 重连成功：继续传输，已保存至相册的照片会自动跳过。
  • 持续无法连接：通常是相机端已关闭热点。请在相机端重新开启 Wi-Fi，返回应用点击「继续连接」。

应用在后台连接中断

此情况表明系统在后台强制清理了 Z-Sync。请返回参考「保持稳定连接的最佳设置」一节，将省电策略修改为无限制，并允许通知。

在小米设备上，该设置尤为关键，配置正确后切出应用十余分钟亦可保持连接。若设置后依然断开，请检查系统 WLAN 设置中是否开启了「自动切换到移动数据」等智能网络选项，尝试将其关闭。

相机正连接其他应用

  1. 彻底退出 SnapBridge（若无需使用建议卸载）。
  2. 前往手机「设置 → WLAN」，若仍记录着相机网络，请点击并选择「忘记此网络」。
  3. 返回 Z-Sync，点击「重试」。

系统授权意外取消

应用会自动返回连接页。请重新点击「连接相机」，并在系统弹窗中选中 NIKON 开头的网络，点击「允许」或「连接」。

相册中未找到照片

  • 照片存放于 Pictures/Z-Sync，视频存放于 Movies/Z-Sync。请在相册的「文件夹」或「相册夹」视图中查找，避免仅在“时间轴/照片”流中翻阅。
  • 部分系统相册存在刷新缓存，可尝试下拉刷新页面，或重启相册应用。

连接相机时的网络说明

此属正常现象。手机连接的是相机的局域 Wi-Fi，该网络本身无法访问外网。若需在传图时保持设备联网，请确保手机已开启移动数据（流量），系统通常会自动通过蜂窝网络处理外部网络请求。如果未开启移动数据，连接相机期间将无法上网。传图完毕后断开 Z-Sync，手机即会自动恢复原网络。

导出日志与反馈

若问题反复出现且上述方法均无效，请导出系统日志以供排查。无需连接电脑或安装其他工具。

  1. 首先让问题复现一次。请按照出错时的步骤重新操作一遍，确保日志记录了最新的错误场景。
  2. 返回连接页面。连接断开后，应用会自动回到该页面。
  3. 点击页面底部、版本号右侧的「导出日志」。
  4. 保存日志文件后，请将其发送至 小红书用户交流群 内。
日志文件不包含任何私人照片内容。文件超过 6 小时会自动清理，手机本地最多保留 5 个，不会占用存储空间。遇到问题请尽快导出，以免日志过期丢失。

反馈时请补充以下信息：手机型号及系统版本、操作到哪一步出现的问题、屏幕上的具体提示文字、以及大概发生的时间。
