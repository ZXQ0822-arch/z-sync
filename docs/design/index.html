第一次连接

  • 1A 首页

    01a-home.html。点「连接相机」弹出「相机 Wi-Fi 已开启？」。取消留在这一页。确认进入 01b-connecting-back.html。

  • 1B 连接中返回

    01b-connecting-back.html。正在连接。返回回到 01a-home.html。

第二次连接

  • 2A 首页

    02a-home.html。正在自动连接。尝试次数每秒加一，并写着「请确认相机Wi-Fi已开启」。确认取消自动连接后进入 02a-home-return.html。

  • 找到的相机

    02a-home-return.html。先显示找到的相机和「是否连接这个相机」，密码与「连接相机」在一起，下面是「已保存的相机连接」。连接进入 02a-connecting.html。

  • 正在连接

    02a-connecting.html。返回回到 02a-home-return.html。
