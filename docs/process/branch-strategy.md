# 分支

主分支叫 `master`。仓库里没有 `main`。提交只留在本机，不推远程。

功能和缺陷都不在 `master` 上直接改。每次从当时的 `master` 拉一条新分支，这一条测过之后再合回 `master`。

## 名字

| 种类 | 分支 | 例子 |
| --- | --- | --- |
| 功能 | `feature/` 加短英文 | `feature/date-groups` |
| 缺陷 | `bug/` 加短英文 | `bug/empty-password-connect` |

一条分支只做一件事。功能不放进 `bug/`，缺陷不放进 `feature/`。

这条约定之前留下的 `fix/` 分支不再继续加提交。新的缺陷用 `bug/`。

## 提交

- 说明用英文。
- 一次提交只做一件事。权限、日志、版本号、错误显示各自分开。
- 每个缺陷单独一次小提交。
- 改了 `shared/`，提交前跑 `./gradlew :shared:test`。
- 全部缺陷都改完并测过之后，版本号再单独提交一次。没有要装到手机时，不升版本。

## 合回

做完并测过，再合进 `master`。能快进就快进。不合还没测完的半截。不推远程。

合进 `master` 之后，这条分支的工作就算结束。下一条再从新的 `master` 拉。
